The extension is the only way posts get in. Here's how to set it up.

Install the extension

Load it straight from the project folder, not from a zip. Chrome reads an unpacked extension off disk every time it starts, so pointing it at the real folder means updates arrive on their own. A zip is a frozen copy and will never change.

{% include "_install_steps.html" %}
Updates are automatic from here. The extension checks this dashboard every minute and reloads itself when the files on disk change — no removing and re-adding. It waits until you're not mid-capture, and any Facebook tab left open will prompt you to refresh it.
Sharing it with someone else

A zip is the right format for handing the extension to another person, since they won't have the project folder. It won't auto-update for them — they'll need a fresh zip each time.

How scoring works

Every post is compared to the median post in its own group, not to posts everywhere. That's the difference between "this got a lot of likes" and "this broke out."

  • Breakout — 5× the group median or more
  • Strong outlier — 3× to 5×
  • Above baseline — 1.5× to 3×
  • Typical — around the median

Engagement is weighted: shares count 5×, comments 3×, reactions 1× — shares put a post in front of a new audience, so they signal reach best. A source needs 8+ posts before it gets scored at all.

Worth knowing

The extension reads posts already rendered in your own logged-in browser — it doesn't use the Facebook API (no API exposes group engagement) and doesn't log in for you. Automated collection is against Facebook's terms of service, which matters if you later want to publish this on the Chrome Web Store. For internal research use, it stays on your machine.
