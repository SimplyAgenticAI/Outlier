The dashboard is running on this machine, so point Chrome straight at the project folder. It reads those files off disk on every start, which means updates arrive on their own — no re-installing.

1
Open the extension folder

Opens a File Explorer window at the right place. Leave it open — you'll drag from it in step 4.

{{ extension_path }}
2
Open Chrome's extensions page

This can't be a link — Chrome blocks pages from opening its own settings. Copy it and paste into the address bar.

chrome://extensions
3
Turn on Developer mode

Top-right corner of that page.

{% include "_diagram_devmode.html" %}
4
Drag the folder onto the page

Drag extension from Explorer straight onto the Chrome window. No file picker involved.

{% include "_diagram_drag.html" %}

Prefer buttons? Click Load unpacked, then paste the copied path into the file dialog's address bar and hit Select Folder.

5
Connect it to your account

One click — this page hands the extension its address and a key. Reload this page first if the button doesn't appear.

Checking for the extension…

6
Open a Facebook group and press Start

A panel appears bottom-right showing what it's reading. That's the last time you'll do any of this.

Updates are automatic from here. The extension checks this dashboard every minute and reloads itself when the files change. It waits until you're not mid-capture, and any Facebook tab left open will prompt you to refresh it.
Sharing it with someone else

A zip is right for handing the extension to another person, since they won't have this project folder. It won't auto-update for them.
