{# Illustrated install walkthrough. The folder picker is where people get stuck, so each step shows what the screen actually looks like. #}
1
Open the extension folder

This opens a File Explorer window at the right place. Leave it open — you'll drag from it in step 4.

{{ extension_path }}
2
Open Chrome's extensions page

This can't be a link — Chrome blocks pages from opening its own settings. Copy it and paste into the address bar.

chrome://extensions
3
Turn on Developer mode

Top-right corner of that page. Without it there's no Load unpacked button at all.

4
Drag the folder onto the page

Easiest way: drag the extension folder straight from Explorer onto the Chrome window. No file picker involved.

Prefer buttons? Click Load unpacked, then paste the copied path into the file dialog's address bar and hit Select Folder.

5
Open a Facebook group and press Start

A panel appears bottom-right showing what it's reading. That's it — you won't have to do any of this again.
